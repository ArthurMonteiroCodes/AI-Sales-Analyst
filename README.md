# AI Sales Analyst

Aplicação de análise de vendas com Python, Streamlit,
Pandas e Plotly.

## Objetivo

Desenvolver uma aplicação capaz de importar dados de vendas,
calcular indicadores, gerar visualizações interativas e,
futuramente, utilizar inteligência artificial para produzir
análises e recomendações.

## Tecnologias

- Python
- Streamlit
- Pandas
- Plotly

## Status

Em desenvolvimento.

## Como executar

1. Clone o repositório.
2. Crie um ambiente virtual Python.
3. Instale as dependências:

   pip install -r requirements.txt

4. Execute:

   streamlit run app.py
